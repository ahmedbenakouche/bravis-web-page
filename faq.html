Installation et connexionInstallation & sign-in

Le module n’apparaît pas dans Slicer.The module does not show up in Slicer.

Vérifiez que Additional module paths (Edit → Application Settings → Modules) pointe bien vers le dossier CollaborativeVersioning, puis redémarrez Slicer. Le module se trouve dans la catégorie Informatics, sous le nom BRAVIS. Voir l’installation.

Check that Additional module paths (Edit → Application Settings → Modules) points to the CollaborativeVersioning folder, then restart Slicer. The module is in the Informatics category, named BRAVIS. See installation.

Message « The xxhash package is required… »“The xxhash package is required…” message

Le stockage des segmentations utilise xxhash. Dans la console Python de Slicer :

Segmentation storage uses xxhash. In Slicer’s Python console:

slicer.util.pip_install("xxhash")
Git ou GitHub CLI (gh) introuvable.Git or GitHub CLI (gh) not found.

Installez-les, vérifiez dans un terminal avec git --version et gh --version, puis redémarrez Slicer pour qu’il les trouve dans le PATH.

Install them, check in a terminal with git --version and gh --version, then restart Slicer so it finds them on the PATH.

La connexion GitHub n’aboutit pas.GitHub sign-in does not complete.

Si un compte gh est déjà présent, utilisez Continue ou Switch account dans la fenêtre GitHub account. Sinon, cliquez sur I have signed in seulement après avoir collé le code sur github.com/login/device et autorisé l’accès. Si Cannot reach GitHub apparaît : Try again, ou Local mode pour travailler hors ligne sur les projets déjà présents. En dernier recours : Disconnect puis reconnectez-vous. Voir la connexion.

If a gh account is already present, use Continue or Switch account in the GitHub account window. Otherwise, click I have signed in only after pasting the code at github.com/login/device and authorizing. If Cannot reach GitHub shows: Try again, or Local mode to work offline on projects already on this computer. Last resort: Disconnect, then sign in again. See sign-in.

Quels atlas sont pris en charge ?Which atlases are supported?

Allen Mouse Brain Atlas et Allen Human Brain Atlas sont intégrés. Toute autre hiérarchie peut être chargée en JSON (atlas_name + tree) ou créée avec l’éditeur d’ontologie. Voir les ontologies.

Allen Mouse Brain Atlas and Allen Human Brain Atlas are built in. Any other hierarchy can be loaded as JSON (atlas_name + tree) or built with the ontology editor. See ontologies.

Versions et partageVersions & sharing

Quelle différence entre Save et Share ?What is the difference between Save and Share?

Save enregistre une version sur votre ordinateur (cadre en pointillés). Share la publie sur le projet partagé (cadre plein), pour toute l’équipe.

Save records a version on your computer (dashed border). Share publishes it to the shared project (solid border), for the whole team.

Share est refusé alors que ma branche semble bonne.Share is refused although my branch looks fine.

Avant d’envoyer, BRAVIS vérifie tout le projet partagé, pas seulement la branche affichée : main ou une autre branche est peut-être en avance. Ouvrez Compare with shared, choisissez une action, Validate, puis réessayez.

Autres causes : rien de nouveau à partager, cadenas junior, ou review 🔵 ouverte sur la branche de tâche.

Before sending, BRAVIS checks the whole shared project, not only the branch on screen: main or another branch may be ahead. Open Compare with shared, pick an action, Validate, then retry.

Other causes: nothing new to share, junior padlock, or an open 🔵 review on the task branch.

Mes collègues ne voient pas mes versions.My colleagues cannot see my versions.

Vérifiez que vos versions ont un cadre plein (Share effectué). Ensuite, chaque collègue doit faire Compare with shared / Update de son côté : les copies locales ne se mettent pas à jour toutes seules.

Check that your versions have a solid border (Share done). Then each colleague must run Compare with shared / Update on their side: local copies do not update by themselves.

La cloche affiche ⚠.The bell shows ⚠.

Votre copie locale n’est plus alignée avec le projet partagé (quelqu’un a fait Share, Assign ou Accept). Ouvrez la cloche puis Compare with shared.

Your local copy is no longer aligned with the shared project (someone ran Share, Assign or Accept). Open the bell, then Compare with shared.

Pourquoi je ne vois pas le bouton Merge ?Why don’t I see the Merge button?

Merge est dans les Version details d’un nœud, pas dans le panneau principal. Il n’apparaît pas si :

  • le nœud n’est pas le bout de sa branche, ou n’est pas encore partagé ;
  • la branche est déjà intégrée dans sa cible ;
  • c’est une branche de tâche (il faut passer par Request review / Accept) ou un nœud …/start ;
  • le parent est déjà mergé plus haut ;
  • votre rôle ne le permet pas (junior hors de sa tâche).

Voir les règles de Merge.

Merge lives in a node’s Version details, not in the main panel. It does not show when:

  • the node is not its branch tip, or is not shared yet;
  • the branch is already in its target;
  • it is a task branch (use Request review / Accept) or a …/start node;
  • the parent is already merged higher up;
  • your role does not allow it (junior outside their task).

See the Merge rules.

Puis-je supprimer une version déjà partagée ?Can I delete an already shared version?

Non. Delete dans les Version details ne concerne que les versions locales (pointillés). L’historique partagé est conservé.

No. Delete in Version details only applies to local versions (dashed). The shared history is kept.

J’ai perdu mon travail en changeant de version.I lost my work when switching versions.

Switch charge une autre version à la place de l’état actuel. Faites toujours Save avant un Switch si vous voulez garder ce que vous avez fait.

Switch loads another version in place of the current state. Always Save before a Switch if you want to keep what you did.

Collaboration

Je suis bloqué par un cadenas 🔒.I am blocked by a 🔒 padlock.

En junior, vous ne pouvez écrire (Save, Share) que sur les branches de vos tâches et leurs sous-branches. Faites Switch sur un nœud sans cadenas de votre tâche. Sans tâche active, demandez à un senior de vous en assigner une. Voir les permissions.

As a junior, you can only write (Save, Share) on your task branches and their sub-branches. Switch to a node of your task without a padlock. Without an active task, ask a senior to assign you one. See permissions.

Je ne peux pas demander de review.I cannot request a review.

Request review apparaît sur le bout partagé de la branche de tâche. Faites d’abord Share. Si la tâche est déjà 🔵, une review est en attente : attendez Accept ou Decline.

Request review shows on the shared tip of the task branch. Share first. If the task is already 🔵, a review is pending: wait for Accept or Decline.

Mon collègue invité ne voit pas le projet.My invited colleague cannot see the project.

Il doit accepter l’invitation : cloche 🔔 → Invitations → Join. Le projet apparaît alors dans sa liste Project ; il fait Open.

They must accept the invitation: 🔔 bell → Invitations → Join. The project then shows in their Project list; they click Open.

Deux juniors peuvent-ils travailler sur la même tâche ?Can two juniors work on the same task?

Oui : une tâche = une branche partagée par tous les juniors cochés. Un seul demande la review (🔵), l’autre attend. Accept clôture la tâche pour les deux.

Yes: one task = one branch shared by all ticked juniors. Only one requests the review (🔵), the other waits. Accept closes the task for both.

Où sont stockées nos données ?Where is our data stored?

Dans un dépôt GitHub privé créé pour le projet, et dans une copie locale sur chaque ordinateur. Seules les personnes invitées y ont accès. Voir le stockage.

In a private GitHub repository created for the project, and in a local copy on each computer. Only invited people have access. See storage.
